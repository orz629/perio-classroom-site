關於本站

製作單位

「三總牙周小教室」是三軍總醫院牙周病科的病人衛教影片系列，由陳穎吾醫師撰寫腳本與製作，幫助病人在門診之外，也能把重要的照顧方法帶回家。

內容如何產生

每支影片的醫學說法都經牙周病專科醫師審查，並附上參考文獻（PubMed 編號 PMID），您可以在每支影片頁面最下方查看。

免責聲明

本網站內容僅供衛教參考，不能取代專業診斷與治療。每個人的狀況不同，您自己的病情與治療方式，請於門診時和醫師討論。

本網站不提供線上諮詢，也不回覆個人病情問題。

隱私聲明

本站不需要登入，不設表單，也不蒐集您的個人資料。

影片由 YouTube 提供播放，使用 YouTube 的隱私強化模式；播放影片時，YouTube 的資料處理依其隱私權政策。本站由 GitHub Pages 代管，主機的連線紀錄依 GitHub 的隱私權政策處理。
